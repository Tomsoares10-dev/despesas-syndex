# Despesas de viagem – Syndex

App de celular para lançar as despesas de viagem (com foto da nota) e gerar o relatório RQ 04 079 em PDF único: o relatório e as notas, 4 por folha.

- Cada pessoa usa no próprio celular. Os lançamentos e as fotos ficam guardados só no aparelho de quem usa; nada é enviado para este site.
- No iPhone: abra o link no Safari → Compartilhar → "Adicionar à Tela de Início" e use sempre pelo ícone.
- Ao fechar a viagem: Gerar relatório → PDF para gov.br → Salvar ou enviar.
